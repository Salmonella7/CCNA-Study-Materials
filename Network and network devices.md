Switches:
- used  to forward traffic in a LAN (local area network)
- CISCO Catalyst 9200
- Has many ports for end hosts
- no connectivity between LANs

Routers:
- ISR1000
- fewer ports (relatively few)
- used to provide connectivity between LANs via the internet

Firewall:
- protects the network
